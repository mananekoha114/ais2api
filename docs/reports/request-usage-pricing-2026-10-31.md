# 模型目录、请求记录与参考费用验证

日期：2026-10-31。覆盖以上游 `4f56551` 为基线的模型目录持久化、逐请求记录、参考计价与 WebUI 功能。

## 行为与数据边界

模型发现成功后，按执行账号原子替换保存完整目录及发现时间；失败保留上次结果，重启后仍可读取。客户端模型列表和模型页加载只读取本地，按当前、首选、首个账号的顺序选择账号；该账号没有保存目录时使用 `configured_models`。首次使用需要在模型页执行“实时发现”，或在服务运行时执行 `ais2api models list`。

三个生成接口通过鉴权后，每次客户端调用建立一条请求记录。内部重试归入该请求的尝试列表；请求次数归属最终执行账号，用量和费用按各尝试的消耗账号归集。生成完成与 HTTP 传输完成分别记录，流式 HTTP 200 不代表生成成功。两端结束后，以同一 SQLite 事务写入终态和累计，重复终结或重启恢复不重复计数。尝试结束时先保存已确认的用量，避免生成端尚未终结时丢失该次消耗。

请求详情只保存模型、账号、接口、状态、耗时、允许的生成设置、用量与报价快照，不保存消息、回答、Cookie、API Key、工具描述或协议签名。WebUI 请求记录默认设备本地时区的今天；统计概览默认累计。列表使用固定查询边界分页，手机生成设置按名称在上、值在下排列。

`PROHIBITED_CONTENT` 等内容拦截计为失败，保留停止原因、已收到的正文和可确认用量。Chat Completions 返回 `content_filter`，Gemini 保留原始 `finishReason`，Responses 返回 `incomplete`；记录失败不增加生成重试或账号惩罚。

数据库支持版本 1 至 3 的升级。版本 3 在事务中修正保留明细的计数及费用贡献，同时保留已过期明细对应的累计和原有 `legacy_records`。新明细默认保留 90 天，可通过 `request_retention_days` 调整；删除过期明细不减少累计。重置统计清除新旧累计和已结束明细，存在活动请求时拒绝。

## 参考计价

价格来自 LiteLLM 的 Google 直连目录，并由 models.dev 的 Google 目录补充，按实际模型精确匹配。缺少或超过 24 小时的价表由后台联网更新；失败保留旧价，失败重试至少间隔一小时。下载使用固定 HTTPS 地址、响应大小与超时限制，不向价格源发送生成正文或账号凭据。

单价以整数皮美元/token、金额以整数纳美元保存，每次尝试固定使用执行时的报价。思考已包含在内部输出 token 总量中，不重复收费；缓存输入从输入总量拆分。更新价表不重算历史费用。

`amount_nano` 表示全部尝试均完整计价的请求小计；`known_amount_nano` 还纳入部分请求中可确认的尝试费用。已知零与完全未知分别表达，未知不能当作免费。搜索、非文本模态及其他无法还原的额外收费维度保持未完整计价；这些金额是参考估算，不是实际账单。

## 合成 HTTP、恢复与真实浏览器

三种协议各运行普通与流式合成 HTTP 请求，共六次：生成源先输出 `hello ` 与 `world`，再以 `PROHIBITED_CONTENT` 结束。六次均保留两段正文、用量和费用，HTTP 为 200，本地状态为 failed，Responses 为 incomplete；生成源调用恰好六次，没有额外重试。正常 `MAX_TOKENS` 与内容拦截有独立断言。

独立临时配置、数据和端口下，使用版本 2 的五条合成记录，覆盖正常完整、拦截完整、拦截部分、全未知和已知零。升级后为 2 次成功、3 次失败，已知小计 $0.34428；完整 2 次、部分 2 次、未知 1 次。停止并重启后累计结构和金额相同，没有重复计入。回归还覆盖迁移失败回滚、过期明细累计保留，以及尝试结束但生成端未终结时的恢复。

真实 Chromium 使用桌面 1280×900、手机 390×844 视口访问隔离实例，检查模型页、统计概览、请求记录和详情。通过网络拦截返回合成发现结果，确认目录、来源和时间一起更新，随后发现失败仍保留目录和时间；没有调用 Google。

手机上测量最大输出 Tokens、温度、思考预算、显示思考四项：标签和数值不重叠，文字位于容器内，页面没有水平溢出。部分费用、内容拦截失败、已知零与完全未知显示符合预期，未出现浏览器运行时异常，并人工检查模型页和详情截图。临时服务和浏览器已停止，截图、数据库与浏览器资料未入库。
